# SuperTrunfo-Logica-em-C-NivelAventureiro
Continuação do jogo Super Trunfo, dessa vez com a implementação de menu deixando-o mais interativo e também com um código mais limpo.
Intruções para utilização:
1 - Cadastre as informações das cartas.
2 - Escolha 1 opção para que seja feita a comparação das cartas. O programa irá dizer qual carta é a vencedora.
